# PalindroneCheckerApp

What is a Palindrome?

A palindrome is a word or sentence that reads the same forward and backward.

Examples:

madam ✅

racecar ✅

hello ❌

How It Works

The program takes input from the user.

It reverses the text.

It compares the original text with the reversed text.

It prints whether it is a palindrome or not.
